# 💰 Bank Account System (Java - Object-Oriented Programming)

---

## 🇺🇸 English

A simple banking system developed in Java, focused on Object-Oriented Programming (OOP) principles and clean architecture.

This project simulates basic banking operations such as deposits, withdrawals, transfers, and transaction history tracking.

### 🚀 Features

* ✔ Create checking and savings accounts
* ✔ Deposit and withdraw money
* ✔ Transfer between accounts
* ✔ Transaction history tracking
* ✔ Interest application (savings account)
* ✔ Console-based interaction

---

### 🧠 Concepts Applied

* Object-Oriented Programming (OOP)
* Inheritance and polymorphism
* Encapsulation
* Separation of concerns
* Lists and data structures
* Date and time API (`LocalDateTime`)
* Business logic modeling

---

### 📁 Project Structure

```
Main.java              → Application entry point  
Account.java           → Base account class  
CheckingAccount.java   → Checking account implementation  
SavingsAccount.java    → Savings account implementation  
Transaction.java       → Transaction model  
```

---

### ▶️ How to Run

```bash
# Clone the repository
git clone https://github.com/TiagoFran/oop-banking-system.git

# Compile
javac *.java

# Run
java Main
```

## 🇧🇷 Português

Sistema bancário simples desenvolvido em Java com foco em Programação Orientada a Objetos (POO) e modelagem de regras de negócio.

O projeto simula operações bancárias como depósito, saque, transferência e histórico de transações.

### 🚀 Funcionalidades

* ✔ Criação de conta corrente e poupança
* ✔ Depósitos e saques
* ✔ Transferência entre contas
* ✔ Histórico de transações
* ✔ Aplicação de juros (conta poupança)
* ✔ Interação via console

---

### 🧠 Conceitos Aplicados

* Programação Orientada a Objetos (POO)
* Herança e polimorfismo
* Encapsulamento
* Separação de responsabilidades
* Estruturas de dados (listas)
* API de data e hora (`LocalDateTime`)
* Modelagem de regras de negócio

---

### 🎯 Objetivo

Este projeto foi desenvolvido para praticar conceitos de POO aplicados a um sistema mais próximo de um cenário real.
